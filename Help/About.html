The About file

This text is Help\About.html, compiled into the program as a resource and shown after the lines when pbShowAboutFile is True - which it is for a program that binds a file. Set it to False in Activate_About, rebuild, and the page ends with the lines above.

A file carries what a line cannot:

  • paragraphs, headings, lists and bold, in the dialog's own look (the library's ftabout.css);
  • a link the browser opens: www.rdctools.com;
  • and as much of it as you like - the page scrolls.
